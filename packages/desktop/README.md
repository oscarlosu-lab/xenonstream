# XenonStream Desktop

[![Build Workflow](https://github.com/oscarlosu-lab/xenonstream/actions/workflows/build.yml/badge.svg)](https://github.com/oscarlosu-lab/xenonstream/actions/workflows/build.yml)

**XenonStream** is an open-source, cross-platform desktop client for **Xbox Cloud Gaming (xCloud)** and **Xbox Remote Play**, built with TypeScript, Nextron, Electron 45, and [`xbox-xcloud-player`](https://github.com/unknownskl/xbox-xcloud-player).

See the root [README.md](../../README.md) ([Español](../../README_ES.md)) and [CHANGELOG.md](../../CHANGELOG.md) for full documentation, downloads, and local development instructions.
