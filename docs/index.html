Frequently Asked Questions

How is XenonStream different from the official Xbox app or legacy clients?

XenonStream is a standalone cross-platform client shipping 1440p streaming, HEVC/AV1 decoding, Linux VA-API & Wayland, macOS Universal DMG + mic entitlements, configurable Remote Play ports, AMD FSR 1.0 / CAS (WebGL2), RTX VSR passthrough, Clarity Boost, LAN host-first ICE, encrypted multi-account tokens, 4-player co-op, 13 languages, Electron 45, an instant-collapse top bar, and an F9 draggable real-time FPS HUD.

Does it work on Steam Deck, Linux, macOS, and Windows handhelds?

Yes. It runs natively on Windows 10/11 (including ROG Ally, Legion Go, and MSI Claw), Linux / SteamOS (Flatpak, AppImage, DEB), and macOS (Universal DMG) with gamepad UI navigation, vibration support, custom button remapping, and real-time GPU upscaling (FSR 1.0 / CAS / Clarity Boost).

Does the FPS counter show real live FPS and can I hide the top bar instantly?

Yes. XenonStream polls WebRTC inbound-rtp video statistics every second to display the actual decoded framesPerSecond in a draggable overlay (toggled with F9 and clamped to the window), and provides a compact ▲/▼ chevron button right below the stream bar to hide or restore it immediately.

Is XenonStream free and open source?

Yes, XenonStream is 100% free and MIT-licensed. You can inspect the full source code, 98 automated tests, and cross-platform CI workflows on GitHub.
